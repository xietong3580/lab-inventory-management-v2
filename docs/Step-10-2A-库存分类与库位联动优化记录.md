# Step 10-2A 库存分类与库位联动优化记录

> **日期**：2026-06-28
> **类型**：前端优化，不修改后端/数据库
> **前置条件**：Step 10-1D 正式导入验收通过，真实库存分类规划已记录

---

## 一、背景

公司实际库存不是按"耗材 / 试剂 / 设备"管理，而是按库存区域和库位管理。

Step 10-1D 已记录真实库存分类规划（4 类 + 29 库位），本轮在此基础上将 Products 页面的"分类"从旧的通用产品分类优化为真实业务使用的"库存分类"，并实现库存分类与库位的联动。

---

## 三、实现内容

### 3.1 新增文件

**src/constants/inventoryLocations.js** — 库存分类与库位常量文件

导出内容：

| 导出 | 类型 | 说明 |
|------|------|------|
| `INVENTORY_CATEGORIES` | `string[]` | 4 个真实库存分类 |
| `INVENTORY_LOCATION_OPTIONS` | `Record<string, string[]>` | 各分类对应的可选库位 |
| `getLocationOptionsByCategory(c)` | `(c: string) => string[]` | 获取某分类的库位选项 |
| `getDefaultLocationByCategory(c)` | `(c: string) => string` | 获取某分类的默认库位 |
| `isRealInventoryCategory(c)` | `(c: string) => boolean` | 判断是否为真实库存分类 |
| `buildCategoryOptions(products)` | `(products: any[]) => Option[]` | 构建筛选下拉选项（真实分类优先 + 旧分类追加） |

### 3.2 修改文件

**src/pages/Products.jsx** — 5 处改动：

1. **筛选区下拉**：从旧的"全部分类 / 耗材 / 试剂 / 设备"改为动态构建的"全部库存分类 / 2楼库存 / 3楼库存 / 刘晓冬安捷伦库存 / 尚工安捷伦库存 [+ 旧分类（如存在）]"

2. **产品列表表头**："分类" → "库存分类"

3. **新增/编辑弹窗**：
   - "分类"标签 → "库存分类"
   - 分类下拉改为真实库存分类 + 编辑中的旧分类（如有）
   - 存储位置从自由文本改为条件渲染：
     - 真实库存分类 → 库位下拉选择（联动）
     - 旧分类 → 自由文本输入（兼容）

4. **库存分类→库位联动**：`handleFormChange` 中新增联动逻辑——切换库存分类时自动设置默认库位

5. **默认值更新**：新增产品默认分类从"耗材"改为"2楼库存"

## 四、兼容策略

### 4.1 旧数据兼容

- 系统中已有"耗材""试剂""设备"等旧分类产品 **不会被删除**
- 筛选下拉在 4 个真实分类后追加旧分类选项，确保旧数据仍可被筛选
- 编辑旧分类产品时，分类下拉包含该旧分类选项，可正常回显
- 旧分类产品的存储位置使用自由文本输入，不受联动影响

### 4.2 编辑切换分类时的库位处理

- 切换库存分类后，库位自动设置为新分类的默认值
- 2楼/3楼 → 清空库位（用户需重新选择）
- 刘晓冬/尚工 → 自动设为"专用区域"
- 不会发生"2楼库位 E2 出现在 3楼库存 产品中"的数据不一致

### 4.3 不做的事情

- 不修改数据库结构（`category` 和 `location` 字段名不变）
- 不修改后端 CSV 导入逻辑
- 不影响现有的关键词搜索、库存状态筛选、库存区间筛选
- 不批量修改已有产品的分类值

## 五、人工验收指引

### 5.1 筛选下拉验收

1. 打开产品管理页面
2. 查看筛选区"库存分类"下拉：
   - 第一项：全部库存分类
   - 后续：2楼库存 / 3楼库存 / 刘晓冬安捷伦库存 / 尚工安捷伦库存
   - 如有旧数据：追加耗材 / 试剂 / 设备
3. 选择"2楼库存"→ 仅显示 category = 2楼库存 的产品

### 5.2 产品列表表头验收

- 表头显示"库存分类"，不再显示"分类"

### 5.3 新增产品验收

1. 点击"新增产品"
2. 库存分类默认选中"2楼库存"
3. 存储位置显示为下拉，可选 A1~F4
4. 切换为"3楼库存"→ 存储位置变为 3-1~3-5
5. 切换为"刘晓冬安捷伦库存"→ 存储位置自动变为"专用区域"
6. 切换回"2楼库存"→ 存储位置清空，需重新选择

### 5.4 编辑产品验收

1. 编辑一个已导入的真实产品（如 SA22137418，2楼库存 / E2）
2. 确认库存分类回显为"2楼库存"
3. 确认存储位置回显为"E2"
4. 切换库存分类为"3楼库存"→ 存储位置自动清空
5. 取消不保存

### 5.5 旧数据兼容验收

- 如有旧分类产品（耗材/试剂/设备），编辑时：
  - 分类下拉包含该旧分类
  - 存储位置为自由文本输入
  - 可正常保存
