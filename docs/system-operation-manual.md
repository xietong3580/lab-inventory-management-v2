# 库存系统功能介绍与使用说明

> 版本：V2/V3 Step 10-8A
> 更新时间：2026-07-03
> 适用人员：系统日常使用人员（管理员、查看人员）

---

## 一、系统简介

库存自动化管理系统是一套企业级库存管理工具，用于统一管理产品信息、库存数量、出入库记录和维护数据安全。

---

## 二、功能介绍

### 仪表盘
展示系统关键数据概览：产品总数、库存状态分布、近期出入库趋势、低库存产品数量等。适合日常打开后快速了解库存整体状况。

### 产品管理
维护产品基础资料的核心页面。包含：
- 产品名称、SKU 编码（唯一标识号）
- 库存分类（2楼库存、3楼库存、刘晓冬库、尚工库等）
- 当前库存数量、最低库存预警值
- 单位（个、盒、瓶、包、套）
- 存储位置/库位
- 品牌、规格、供应商、备注
- 采购价、售价

### 出入库记录
记录产品的入库（补货、采购到货）和出库（领用、消耗）。每次出入库会自动更新产品库存，并生成台账和操作日志。支持撤销错误操作。

### 低库存预警
展示库存低于最低库存标准的产品，帮助及时补货。

### 操作日志
记录所有管理员的关键操作，可追溯到是谁在什么时间做了什么操作。新增产品、编辑、出入库、撤销、备份、恢复准备等均有记录。

### 系统设置
包含数据库备份创建、备份恢复预检、正式启用前检查、数据安全检查等维护功能，以及修改密码等账号安全功能。

### 导入预览
辅助检查 CSV 文件中的产品数据，核对后预览导入效果。

## 三、日常操作说明

### 如何查询产品库存
1. 点击左侧菜单「产品管理」
2. 在搜索框输入产品名称或 SKU，按回车
3. 可用品牌、库存分类、库位等筛选缩小范围
4. 表格显示 SKU、名称、库存量、状态（正常/低库存）、库位

### 如何新增产品
1. 产品管理页面点击「+ 新增产品」
2. 填写必填信息：SKU 编码、产品名称、库存分类、单位、当前库存、库位
3. 选填：品牌、规格、供应商、备注、采购价、售价
4. 点击「添加产品」保存并关闭弹窗
5. 如需连续录入，点击「保存并继续新增」（分类、单位、库位自动保留）

### 如何编辑产品
1. 在产品列表找到目标产品
2. 点击右侧「编辑」按钮
3. 修改需要更正的信息
4. 点击「更新产品」保存

### 如何入库
1. 点击「出入库记录」
2. 选择或搜索产品
3. 类型选择「入库」
4. 填写入库数量
5. 填写备注（如供应商、入库单号）
6. 保存

### 如何出库
1. 点击「出入库记录」
2. 选择产品，类型选择「出库」
3. 填写出库数量（不能超过当前库存）
4. 填写备注（如领用人、用途）
5. 保存

### 如何撤销错误记录
1. 在出入库记录列表找到错误记录
2. 点击该记录旁的「撤销」
3. 撤销后库存自动恢复

### 如何查看库存台账
1. 产品管理 → 在产品旁点击「台账」
2. 台站显示该产品的完整库存变化历史

### 如何导出 CSV 核对
1. 产品管理 → 先筛选需要导出的范围
2. 点击「导出 CSV」
3. 系统自动安全检查后下载文件
4. 用 Excel 打开 CSV，与外部数据逐条核对

### 如何创建数据库备份
1. 点击「系统设置」
2. 在系统维护区域找到「创建数据库备份」
3. 确认创建

### 如何查看操作日志
1. 点击「操作日志」
2. 按产品名称、操作类型、时间范围筛选
3. 出问题时优先查看操作日志

## 四、录入注意事项

1. **SKU 编码不能重复**，系统会实时检查并提示
2. **产品没有货号**时，可使用内部编号（如 LEGACY-NOCODE-0001），产品名称保持真实
3. **采购价、售价未知**时留空，不要填 0。0 表示免费，留空表示未知
4. **库存数量**请人工确认后准确填写
5. 发现录错时优先使用「撤销」或「编辑」功能修正
6. **不要直接修改数据库文件**，应通过系统功能操作

## 六、常见问题

### 产品没有货号怎么办？
使用内部编号，如 LEGACY-NOCODE-0001 等，产品名称保持真实。

### 采购价、售价不知道怎么办？
留空，不要填 0。后续知道了可以编辑补充。

### 库存数量录错了怎么办？
如果还未正式开始出入库，直接编辑产品修改。已正式使用后，通过出入库记录来调整，并备注原因。

### SKU 重复了怎么办？
确认是否为同一产品。如果是不同产品用了相同 SKU，修改其中一个。

### 产品名称重复了怎么办？
系统会提示但不阻止，可能是不同规格。确认重复后删除多余即可。

### 为什么要导出 CSV 核对？
导出后可与外部数据来源逐条比对，确保产品数量、名称、SKU、库存和库位准确。

### 恢复预检和准备恢复有什么区别？
- 恢复预检：只检查备份文件是否可用
- 准备恢复：在预检通过后再创建一份当前数据库安全备份
- 两者都不会执行真正的恢复操作

### 为什么不建议直接修改数据库文件？
直接修改无法记录日志、容易破坏数据一致性、难以恢复。请通过系统功能操作。
