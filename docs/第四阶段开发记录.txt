2. 新增 _generate_batch_id() 辅助函数（格式: imp-YYYYMMDD-NNN）
3. 新增 POST /api/imports/products/execute 路由：
   - 权限：require_admin（仅 admin，viewer 返回 403）
   - 参数：file (UploadFile), mode (Form, 默认 create_only),
     confirm_backup (Form, 默认 false)
   - 模式校验：仅支持 create_only，否则返回 400
   - confirm_backup 检查：不传 true 则返回业务失败
   - CSV 解析：后端重新调用 _parse_and_validate_csv()，
     不信任前端预览结果
   - 错误分离：将 DB-已存在 SKU 错误（"已存在于数据库中"）
     从 global_errors 中分离为 warning，不阻止导入；
     CSV 内部重复 SKU 和其他校验 error 仍阻止导入
   - 行分类：有真实 error 的行阻止整批；DB-已存在 SKU 的行
     归入 skipped_items
   - 事务写入：同一 Session 内批量创建 Product + AuditLog，
     commit 或 rollback（全部成功或全部失败）
   - 库存口径：仅写入 P0 字段，STOCK_CONTEXT 不写入，
     status 由系统自动计算
   - 审计日志：action_type=PRODUCTS_CSV_IMPORT，
     记录 batch_id / file_name / operator / created_count /
     skipped_count / warning_count / error_count / details JSON
   - 返回结构：包含 success / mode / batch_id / file_name /
     total_rows / created_count / skipped_count /
     warning_count / error_count / created_items /
     skipped_items / warnings / errors / detail / backup_reminder
