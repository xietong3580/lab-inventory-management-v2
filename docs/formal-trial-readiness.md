## 4. 正式试用建议

- **旧系统继续并行保留**：前 1–2 周不要关闭旧库存系统，双向核对。
- **每次大操作前先备份**：特别是批量编辑或出入库前，在设置页创建备份。
- **每日检查 Dashboard**：确认产品总数、低库存数、近 7 日交易数是否合理。
- **首批出入库从少量低风险产品开始**：先选 1–2 个熟悉的产品测试真实出入库流程。
- **出现异常立即停止**：先备份当前数据库（保留现场），再分析问题，不要盲目清空或恢复。
- **不要直接手动修改 inventory.db**：所有操作必须通过系统界面完成。

## 6. 安全注意事项

| 操作 | 风险等级 | 说明 |
|---|---|---|
| 清空业务数据 | **危险** | 需输入确认短语 + 二次弹窗确认，自动创建备份 |
| 恢复数据库 | **危险** | 需备份预检 + 确认短语，会覆盖当前数据 |
| CSV 导入 | **高风险** | 需先预览确认，确认备份后执行创建 |
| 删除产品 | **中风险** | 有交易记录时禁止删除 |
| 用户管理 | **中风险** | 禁止删除 admin 或最后管理员 |

- viewer 账号只能查看，不能做任何写入操作。
- 不要直接手动修改 inventory.db 文件。
- 不要删除备份文件，它们是最重要的恢复手段。
