## 3. 产品管理回归

### 搜索与筛选

- [ ] **SKU 完整搜索**：输入完整 SKU，搜索结果包含目标产品。预期：仅目标产品出现
- [ ] **SKU 部分搜索**：输入 SKU 部分字符（如"PRD-2026"），返回结果包含多款匹配产品
- [ ] **产品名称搜索**：输入产品名称关键词（如"离心管"），返回所有相关产品
- [ ] **品牌筛选**：选择品牌下拉选项，仅展示该品牌产品。预期：待所有产品有品牌数据后启用
- [ ] **库存分类筛选**：分别选择"正常""低库存""全部"，列表正确过滤
- [ ] **库位筛选**：选择不同库位（A 区 / B 区 / 冷藏室等），列表正确过滤
- [ ] **组合筛选**：关键词 + 分类 + 库位同时使用，返回交集结果
- [ ] **重置筛选**：点击重置后，搜索框清空、筛选下拉恢复默认、列表恢复全量

### 产品 CRUD

- [ ] **新增产品**：填写 SKU、名称、分类、库存、单位等 → 保存 → 列表中出现新产品
- [ ] **编辑产品**：点击编辑 → 修改名称/库存等 → 保存 → 列表和详情刷新
- [ ] **P1 字段填写**：新增/编辑时填写 brand / specification / supplier / notes → 保存后编辑回显正确
- [ ] **P1 字段回显**：已有 P1 数据的产品，编辑弹窗中各字段预填正确
- [ ] **库存分类联动**：分类选择"耗材""试剂""设备"等 → 保存后详情和筛选正确
- [ ] **库位联动**：库位填写后 → 库位筛选正确归属
- [ ] **删除产品**：点击删除 → 弹出确认 → 确认后产品从列表消失
- [ ] **删除反馈**：删除成功后有提示（非 alert），删除失败时有错误说明
- [ ] **默认排序**：产品列表默认按 SKU / 添加时间有合理排序

## 4. 出入库新增记录回归

### 产品搜索选择器

- [ ] **打开新建弹窗**：点击"入库"或"出库"按钮 → 弹窗正常打开，产品搜索框自动聚焦
- [ ] **完整 SKU 搜索**：在搜索框输入完整 SKU（如"PRD-2026001"）→ 结果中包含匹配产品
- [ ] **部分 SKU 搜索**：输入部分 SKU → 下拉列表显示模糊匹配结果
- [ ] **产品名称搜索**：输入中文产品名称关键词 → 下拉列表显示匹配结果
- [ ] **品牌搜索**：输入品牌名 → 下拉列表显示该品牌产品
- [ ] **点击选中产品**：点击搜索结果中的产品 → 产品被选中，搜索框关闭，已选产品信息卡显示
- [ ] **Enter 选中第一条**：搜索后按 Enter → 第一条结果被选中
- [ ] **只输入不选中 → 保存拦截**：搜索框输入关键词但未点击选中 → 点保存 → 提示"请先从搜索结果中选择产品"
- [ ] **完全未操作选择器 → 保存拦截**：不操作搜索框直接点保存 → 提示"请选择产品"

### 已选产品信息展示

- [ ] 选中产品后，信息卡展示：产品名称、当前库存数量、单位、分类、库位、库存状态（正常/低库存）
- [ ] 库存状态颜色：正常为绿色系，低库存为橙色/红色系

### 出/入库保存

- [ ] **入库保存成功**：选择产品 → 填写数量 → 点击保存 → 提示"入库记录已保存"→ 弹窗关闭
- [ ] **入库后库存增加**：保存入库后 → 切到产品列表 → 该产品 currentStock = 原值 + 入库量
- [ ] **出库保存成功**：选择产品 → 填写数量 → 点击保存 → 提示"出库记录已保存"→ 弹窗关闭
- [ ] **出库后库存减少**：保存出库后 → 切到产品列表 → 该产品 currentStock = 原值 - 出库量
- [ ] **库存不足出库拦截**：选低库存产品 → 填写超过 currentStock 的数量 → UI 即时红色预警显示 → 保存被拦截提示"库存不足，无法出库"
- [ ] **保存中状态**：保存时按钮文字变为"保存中..."，按钮 disabled，不可重复点击
- [ ] **保存失败提示**：模拟失败（如断网）→ 错误信息显示在模态框内（非 alert），弹窗不关闭

## 5. 撤销交易回归

### 撤销前确认

- [ ] 对 `status: "completed"` 的交易点击"撤销"→ 弹出确认对话框
- [ ] 确认对话框显示：交易产品名称、类型（入库/出库）、数量、操作人
- [ ] 未撤销的交易显示可点击的"撤销"按钮（灰色但可点击）

### 撤销库存回滚

- [ ] **撤销入库**：撤销一笔入库交易 → 对应产品库存减少（回滚入库增量）
- [ ] **撤销出库**：撤销一笔出库交易 → 对应产品库存增加（回滚出库扣量）
- [ ] 撤销成功后，确认对话框关闭，列表刷新

### 重复撤销拦截

- [ ] 已撤销交易（`status: "reversed"`）的"撤销"按钮为禁用状态（灰色 + `cursor-not-allowed`）
- [ ] 即使绕过前端直接调 API，后端返回"此交易记录状态已是'已撤销'，不能重复撤销"

### 撤销状态与提示

- [ ] **撤销中**：确认撤销时按钮文字变为"撤销中..."，按钮 disabled
- [ ] **撤销成功**：页面出现成功提示条，3 秒后自动消失
- [ ] **撤销失败**：有明确错误提示（如产品已被删除），不静默失败
- [ ] 撤销失败时，交易状态不改变、库存不变化

### 台账关联

- [ ] 已撤销的交易在台账中显示（标记为"撤销入库" / "撤销出库"），但 stockChange 为 0，不计入库存变动

## 6. productId 数据一致性回归

> 此检查项在 Step 10-4D 后为必检项。确保交易记录与产品之间通过 productId 稳定关联。

- [ ] **新交易包含 productId**：新增入库/出库后 → 在 localStorage/API 返回数据中确认交易记录包含 `productId` 字段且值正确
- [ ] **撤销优先 productId**：对 productId 正常的交易执行撤销 → 验证按 productId 找到产品（不被产品名称影响）
- [ ] **产品改名后仍可撤销**：修改某产品名称后 → 对该产品的新交易执行撤销 → 仍能正确撤销（通过 productId）
- [ ] **旧交易 fallback productName**：手动删除 localStorage 中某条旧交易记录的 `productId` → 执行撤销 → 通过 productName 匹配成功
- [ ] **productId 指向已删除产品**：若 productId 有值但产品已删除 → 撤销时报明确错误"关联产品不存在，无法撤销交易"
- [ ] **台账 productId 匹配**：通过产品页台账功能 → 能正确关联该产品的所有交易（包括新老记录）
- [ ] **产品重名风险**：确认不存在相同名称的不同产品（若存在，需在数据层面解决）

## 8. Dashboard / Alerts / AuditLog 联动回归

### Dashboard

- [ ] **产品总数**：Dashboard 卡片数值 = 产品列表实际产品数
- [ ] **正常库存数** = currentStock > minStock 的产品数
- [ ] **低库存预警数** = currentStock ≤ minStock 的产品数
- [ ] **最近出入库记录**：Dashboard 最近交易列表 = 交易记录页最新数据
- [ ] 完成一笔交易后刷新 Dashboard → 统计数据正确更新

### Alerts（低库存预警）

- [ ] Alerts 页面低库存列表 = 所有 currentStock ≤ minStock 的产品
- [ ] 手动调整某产品库存使其触发低库存 → 切到 Alerts → 该产品立即出现
- [ ] 手动补充某产品库存使其恢复正常 → 切到 Alerts → 该产品消失
- [ ] 低库存数量与 Dashboard 卡片数值一致

### AuditLog（审计日志）

- [ ] **产品新增**：新增产品后 AuditLog 出现 PRODUCT_ADD 记录
- [ ] **产品编辑**：编辑产品后 AuditLog 出现 PRODUCT_UPDATE 记录
- [ ] **出入库交易**：创建交易后 AuditLog 出现 TRANSACTION_ADD 记录
- [ ] **撤销交易**：撤销交易后 AuditLog 出现 TRANSACTION_REVERSE 记录
- [ ] **CSV 导入**：CSV 正式导入后 AuditLog 出现 CSV_IMPORT 记录
- [ ] **审计日志详情**：日志条目包含时间、操作类型、产品名、操作人
- [ ] **不重复记录**：同一操作在 AuditLog 中只出现一次

## 10. 操作反馈与防重复提交回归

### Loading 状态

- [ ] **产品保存中**：新增/编辑产品点击保存 → 按钮变为"保存中..." + disabled
- [ ] **产品删除中**：删除产品点击确认 → 按钮变为"删除中..." + disabled
- [ ] **出入库保存中**：交易保存点击确认 → 按钮变为"保存中..." + disabled
- [ ] **撤销中**：撤销确认点击"撤销"→ 按钮变为"撤销中..." + disabled

### 错误处理

- [ ] 所有错误提示使用 Toast / 模态框内错误卡片，**不使用 `window.alert()`**
- [ ] 表单验证失败时，错误信息显示在模态框内，模态框不关闭
- [ ] 网络/API 错误时，模态框不关闭，用户可修改后重试

### 防重复提交

- [ ] 操作进行中（loading = true）时，重复点击按钮不会触发第二次请求
- [ ] 操作进行中关闭弹窗按钮 disabled / 忽略
- [ ] 操作完成后 loading 正确恢复，用户可进行下一轮操作
- [ ] 操作失败后按钮恢复可点击状态，页面不会让用户误以为卡死

### 成功反馈

- [ ] 操作成功后出现绿色成功提示条（如"入库记录已保存"）
- [ ] 提示条 3 秒后自动消失，也可手动关闭
- [ ] 成功后相关数据列表自动刷新
