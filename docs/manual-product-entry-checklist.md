# 正式产品手动录入流程与核对清单

> 版本：V2/V3 Step 10-6D
> 更新时间：2026-07-03
> 适用范围：库存自动化管理系统 正式产品主数据手动录入

## 背景

用户决定：正式产品主数据不走批量正式导入主路线，而是由用户逐个手动录入，以保证准确性。

旧系统 CSV / 腾讯共享文档仅作为参考底稿和核对资料。

已有导入预览功能继续保留，作为辅助检查工具，但当前不开发正式批量导入执行。

---

## 1. 正式产品手动录入流程

1. **打开产品管理页面** → 点击「+ 新增产品」
2. **逐条录入产品信息**，优先填写：
   - SKU 编码（必填，唯一）
   - 产品名称（必填）
   - 当前库存（必须人工确认后录入）
   - 库存分类 / 库位
3. **采购价 / 售价**：未知时留空，不要填 0 代替未知
4. 点击「保存并继续新增」继续录入下一条（保留分类、单位、库位、最低库存）
5. 最后一条点击「添加产品」关闭弹窗

## 2. 每批录入建议

### 按库存分类/库位分批
- 建议先录完一个库位的所有产品，再换下一个库位
- 利用「保存并继续新增」功能，库位和分类会自动保留
- 分批可降低出错范围和核对成本

### 每批录入后导出 CSV 核对
1. 在筛选栏选择本批对应的库存分类/库位
2. 点击「导出 CSV」
3. 将导出的 CSV 与旧系统/腾讯文档进行反向核对
4. 确认无误后再继续下一批

### 核对项
- 产品数量是否一致
- 产品名称是否准确
- SKU 编码是否正确
- 库存数量是否与实物相符
- 库位是否正确

## 3. 无货号产品处理

对于旧系统中没有正规货号的产品：

- 可使用迁移编号格式：`LEGACY-NOCODE-0001`、`LEGACY-NOCODE-0002` 等
- 产品名称保持真实名称，便于后续识别
- 后续如需正规化，可通过编辑功能更新 SKU

## 4. 采购价 / 售价未知

- **留空即可**，系统会存储为 null
- **不要填 0**：0 表示"免费/零价格"，与"未知"语义不同
- 后续可通过编辑功能补充价格信息

## 5. 当前库存

- **必须人工确认后录入**
- 不要直接照搬旧系统库存数字，需确认实物库存
- 如有差异，以实物为准，在备注中说明差异原因

## 6. 正式启用前检查清单

在开始正式出入库之前，请确认以下事项：

- [ ] 所有产品已录入完毕
- [ ] 已导出产品 CSV 并存档
- [ ] 已与旧系统数据进行交叉核对
- [ ] 已通过「设置 → 备份管理」创建数据库备份
- [ ] 已确认各产品当前库存数量与实物一致
- [ ] 已确认库位分配正确

### 创建数据库备份
在设置页面中找到备份管理功能，创建完整备份后再开始正式出入库操作。

---

## 7. 防错机制说明

系统在录入过程中提供以下防错辅助：

| 功能 | 说明 |
|------|------|
| SKU 重复检查 | 输入 SKU 时实时检查，发现重复则阻止提交 |
| 产品名称重复提示 | 黄色警告提示，不阻止提交 |
| 名称+规格重复提示 | 更强的黄色警告，不阻止提交 |
| 保存并继续新增 | 保留分类/单位/库位/最低库存，清空产品特定字段 |
| 录入提示文案 | 弹窗底部提醒关键字段优先核对 |
| 导出核对提示 | 导出按钮旁提示导出后与旧系统核对 |

---

## 8. 旧系统历史出入库记录

- 旧系统历史出入库记录后续仍做只读归档
- 不参与当前库存计算
- 如需查阅历史记录，使用导入预览功能作为参考
