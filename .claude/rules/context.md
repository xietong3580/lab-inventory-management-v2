# 上下文管理规则

## 会话管理
- **不相关任务之间**：主动使用 `/clear` 清理上下文
- **上下文过大时**：先使用 `/context` 检查上下文长度
- **需要继续当前任务但消息过长时**：使用 `/compact` 压缩上下文

## 文件读取优化
- 优先读取必要片段，避免反复整文件重读
- 使用适当的偏移量和限制参数
- 对于大文件，先读取关键部分

## 调研与执行分离
- 复杂调研任务使用 subagent (Explore/Plan 等)
- 调研结论返回主会话后再开始实现
- 保持主会话专注于当前实现任务

## 输出组织
- 保持输出结构清晰（见沟通协议）
- 避免冗长描述，聚焦关键信息
- 技术细节适当抽象，重点说明影响
